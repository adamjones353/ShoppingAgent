# Privacy Policy

Last updated: 2026-05-17

Grocery Shopping Agent is a Chrome extension for meal planning, shopping list management, and assisted grocery shopping on supported retailer websites.

## Data Stored Locally

The extension stores the following data locally in Chrome storage on your device:

- Meals and ingredients
- Meal plans
- Shopping lists
- Product preferences
- Extension settings
- Optional AI request logs
- Your OpenAI API key, if you choose to enter one

## Data Sharing

The extension does not sell user data and does not use third-party analytics.

If AI meal ideas are disabled, the extension does not send meal planning prompts to an AI provider.

If you enable AI meal ideas and provide an OpenAI API key, the extension sends your prompt, recent meal names, and existing meal names to OpenAI to generate meal suggestions. OpenAI handles that data under its own terms and privacy policy.

## Grocery Website Access

The extension runs an overlay on supported grocery websites so you can save product preferences, add products, and move through your shopping list. Product preference data is stored locally in Chrome storage.

## Export

The extension includes a local JSON export feature so you can export your extension data.

## Contact

For privacy questions, contact the publisher using the contact details shown on the Chrome Web Store listing.
